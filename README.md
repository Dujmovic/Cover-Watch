# Cover Watch

A phone-friendly tracker for single bets and teasers. It shows live, with color and icons, whether each bet is covering, on the line, or not covering.

- Open the site, then use your browser's share menu and choose Add to Home Screen.
- Live scores come from ESPN's public scoreboard. The three-dot menu has Test the feed.
- Bets are stored only in the browser on your device. Use Copy backup in the three-dot menu to save them.
